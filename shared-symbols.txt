mapMake PC 공통 GSS 이미지 심볼

공통 저장소: D:\map\styles\symbols
GSS 폴더를 지정한 XML → SLD 생성 시, 해당 GSS 폴더의 전체 BMP/PNG 이미지 심볼을 등록합니다.
원본 심볼 이름 + PNG 내용 식별자로 파일명을 정하므로 축척과 생성 순서가 달라도 동일한 결과를 참조합니다.
동일 파일은 내용을 확인하여 재사용합니다. 원본 이미지나 투명도 결과가 달라지면 별도 버전 파일을 사용합니다.
이전에 만든 심볼은 자동 삭제하지 않습니다. 기존 SLD가 참조할 수 있기 때문입니다.

로컬 사용: 심볼 기본 URL을 비워 두세요. 새 SLD는 공통 저장소의 절대 경로를 참조합니다.
메인에서 SLD를 가져와 .map을 생성해도 공통 저장소의 PNG는 다시 복사하지 않습니다.
HTTP 심볼 기본 URL을 입력하는 기존 서버용 내보내기 방식은 별도로 유지합니다.

기존 SLD/타일의 상대경로를 자동 수정하지 않습니다. 새 방식으로 사용하려면 스타일을 다시 생성하세요.
이 저장소를 참조하는 지도는 동일 PC에서 사용합니다. 다른 PC로 옮길 때는 공통 저장소도 같은 경로에 배치하세요.
이미지 외의 선/면/문자 스타일 규칙은 축척별 XML/SLD에서 계속 관리합니다.

검증: GSS 이미지 486개 변환, 100/50 축척 간 재사용, 기존 PNG 미변경,
SLD의 실제 파일 존재 확인 및 .map SLD 가져오기 중복 복사 방지 통과.
